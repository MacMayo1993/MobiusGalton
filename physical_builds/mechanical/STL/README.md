# STL Files — Mechanical Möbius Galton Board

This folder will contain 3D-printable STL files for all board components.

## Files (to be exported from CAD)

| Filename | Description | Print time (est.) |
|----------|-------------|-------------------|
| `board_frame.stl` | Main board frame | 6 h |
| `peg_row_even.stl` | Even-row peg strip | 45 min |
| `peg_row_odd.stl` | Odd-row peg strip | 45 min |
| `seam_tube_left.stl` | Left helical seam conduit | 2 h |
| `seam_tube_right.stl` | Right helical seam conduit | 2 h |
| `bin_collector.stl` | 14-slot collection bin | 1.5 h |
| `funnel_top.stl` | Ball-drop funnel | 30 min |
| `parity_gate.stl` | Auto-parity entry gate | 45 min |

See `assembly_guide.md` for detailed print settings and assembly instructions.
